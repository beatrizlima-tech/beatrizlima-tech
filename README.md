## ⭐ Featured projects

### 📦 Inventory Management System — Java + Angular

A full-stack inventory application with product management, stock indicators, and a **recycle bin**. Products can be soft-deleted, restored within **30 days**, or permanently removed.

The back-end includes scheduled cleanup of expired records, while the Angular interface provides validation, confirmation dialogs, and feedback messages.

**Stack:** Java, Spring Boot, PostgreSQL, Flyway, Angular 21, TypeScript, JUnit, Vitest.

**Highlights:** REST API integration · business rules · **35 passing Angular tests** · lazy-loaded routes.

🔗 [Back-end repository](https://github.com/beatrizlima-tech/gestao-produtos-api) · [Front-end repository](https://github.com/beatrizlima-tech/gestao-produtos-web)

### 💰 Personal Finance Platform — APIs + Angular + AI

An interconnected set of applications for personal finance management, including user registration and JWT authentication, income and expense tracking, per-user data access, and asynchronous financial report processing.

An internal AI service integrates with OpenAI, MongoDB, and email delivery.

**Stack:** Java, Spring Boot, Spring Security, PostgreSQL, MySQL, MongoDB, RabbitMQ, Angular 21.

🔗 [Finance API](https://github.com/beatrizlima-tech/api-financas) · [Authentication API](https://github.com/beatrizlima-tech/api-autenticacao) · [AI Reports API](https://github.com/beatrizlima-tech/api-agentesia) · [Angular Front-end](https://github.com/beatrizlima-tech/web-financas)

### 📦 Order Processing API — RabbitMQ

A Spring Boot API for managing customers, products, and orders, using MongoDB for persistence and RabbitMQ for asynchronous processing.

**Stack:** Java, Spring Boot, MongoDB, RabbitMQ, Spring AMQP, Swagger / OpenAPI.

🔗 [Orders API](https://github.com/beatrizlima-tech/api-pedidos) · [Payments API](https://github.com/beatrizlima-tech/api-pagamentos)
